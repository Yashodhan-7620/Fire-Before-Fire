What this dashboard does

  • Ingestion — view raw sensor readings as they arrive from each node.
  • Drift Detection — KS-test comparison of recent readings vs. the training-time baseline; a background job checks this automatically and retrains on its own when drift is detected (no Airflow — same dvc repro path as run_batch.bat).
  • Batch Inference — next-period predictions per node from the latest committed features, with SHAP-explained recommendations when a threshold is crossed.
  • Real-time Inference — same prediction + explanation flow computed on-the-fly from each node's most recent live readings.
  • Monitoring — /metrics is scraped by Prometheus; Grafana (top-right link) visualizes it.
